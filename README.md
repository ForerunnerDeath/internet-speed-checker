# Internet Speed Checker

Небольшая CLI-утилита для измерения скорости загрузки по HTTP.

Программа принимает URL, последовательно выполняет 10 GET-запросов, полностью считывает тело каждого ответа, считает среднее время запроса, общий объём загруженных данных и итоговую среднюю скорость.

Ответ читается потоково, поэтому файл не загружается целиком в память.

## Требования

Python 3.11+

## Установка

Создайте виртуальное окружение:

```bash
python -m venv .venv
```

Активация в Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Linux/macOS:

```bash
source .venv/bin/activate
```

Установите проект:

```bash
python -m pip install -e .
```

Для разработки с тестами и инструментами проверки качества:

```bash
python -m pip install -e ".[dev]"
```

## Использование

После установки можно запустить утилиту как CLI-команду:

```bash
speedcheck "https://speed.cloudflare.com/__down?bytes=10000000"
```

Альтернативный вариант:

```bash
python -m speedcheck "https://speed.cloudflare.com/__down?bytes=10000000"
```

Поддерживаются только URL со схемами HTTP и HTTPS.

Пример вывода:

```text

Requests: 10

-------

Total downloaded:     100.00 MB

```

## Как выполняется измерение

Утилита выполняет ровно 10 последовательных HTTP GET-запросов через один HTTP-клиент.

Для каждого запроса таймер запускается до начала HTTP-запроса и останавливается только после полного считывания тела ответа.

Объём загруженных данных считается по фактически полученным байтам, а не по заголовку `Content-Length`.

Итоговая средняя скорость рассчитывается по формуле:

```text
общий объём загруженных данных / суммарное время запросов
```

Такой способ корректнее, чем простое арифметическое среднее скоростей отдельных запросов, если их длительность отличается.

Для отображения используется десятичный мегабайт:

```text
1 MB = 1 000 000 bytes
```

Автоматические retry намеренно не используются, так как дополнительные скрытые запросы исказили бы количество запросов и результаты измерения.

## Тесты

Запуск основного набора тестов:

```bash
pytest
```

Основной набор включает unit-тесты и детерминированный integration test с локальным HTTP-сервером. Для него не требуется доступ в интернет.

Дополнительно есть E2E smoke-тест, который выполняет реальные запросы к внешнему HTTP endpoint. По умолчанию он отключён.

Запуск E2E в Windows PowerShell:

```powershell
$env:RUN_E2E_TESTS="1"
pytest
Remove-Item Env:RUN_E2E_TESTS
```

Linux/macOS:

```bash
RUN_E2E_TESTS=1 pytest
```
